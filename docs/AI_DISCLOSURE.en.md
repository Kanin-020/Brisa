# AI Disclosure

This disclosure is provided in accordance with the [Flathub Generative AI
policy](https://docs.flathub.org/docs/for-app-authors/requirements#generative-ai-policy).

**The entire Brisa project was generated with AI assistance, under continuous
human supervision.**

### Affected parts and approximate extent

- **~100 % of the project**, including:
  - Source code: `src/` (core logic, CLI, desktop/Electron wrapper, web UI).
  - Build tooling and configuration: `scripts/`, `.github/`, `package.json`,
    `electron-builder.yml`, tsconfig files.
  - Documentation: this repository's README, architecture docs, changelog and
    release notes.
  - Packaging and CI assets, including the application icon.
- **Not covered** by this disclosure: third-party content referenced by the
  application (the open-source decompilation projects listed in the port
  manifests and their releases), and any user-provided data (ROMs, mods,
  saves). No third-party code is claimed as AI-generated by this project.

### Nature of the supervision

- An AI assistant proposes code, text and configuration; a human author
  reviews, validates and decides what is included.
- Before each release the project is verified by the human author via the
  repository's own checks (`npm run typecheck`, `npm test`) and manual
  testing.
- Development follows standard practices: tagged versions, conventional
  commits, a maintained changelog and published releases.

This disclosure covers material included in the application and in its
Flathub packaging. It will be updated if the development process changes.
